2. Experiencia de usuario

Los desarrolladores valoran la velocidad: cada paso extra es fricción.

Flujo crítico: del registro a la primera llamada

  1. Registro / login: con GitHub, Google o correo con verificación de un clic.
  2. Credenciales: guiar al usuario a generar su primera API Key de prueba.
  3. Sandbox: copiar un fragmento (cURL o JavaScript) y ver una respuesta exitosa.

Principios

  • Copiar sin fricción: botón "Copiar" en cada bloque de código (pruébalo abajo).
  • Errores claros: indicar el código HTTP y cómo solucionarlo.

3. Interfaz visual

Inspirada en Vercel, Stripe, GitHub Primer y Supabase: limpia, minimalista y con modo oscuro nativo.

Layout principal

  • TopBar: logo, buscador global (Ctrl + K), selector de entorno y perfil.
  • Sidebar: menú jerárquico (Guías, Autenticación, Endpoints, Configuración).
  • Contenido: espacio amplio para texto, tablas o consolas.
  • Panel derecho (opcional): ejemplos de código en pestañas.

Design tokens

Tipografía: Inter o Roboto para la interfaz y JetBrains Mono o Fira Code para el código.
